=== FIDELITY RULES — READ FIRST ===
The files in /design-reference are the SOURCE OF TRUTH. The goal is a 1:1 port to Next.js — not a reinterpretation. Do not redesign, "improve", rename, re-word, re-space or re-time anything.

1. Before building any page or component, read its reference file in full:
   Home.dc.html → app/(store)/page.tsx + components/home/*
   Shop.dc.html → app/(store)/shop/page.tsx + components/shop/*
   Product.dc.html → app/(store)/products/[id]/page.tsx + components/product/*
   Collections.dc.html → app/(store)/collections/page.tsx
   Checkout.dc.html → app/checkout/page.tsx
   SiteHeader.dc.html → Header, SearchSheet, MobileMenu, CartDrawer
   SiteFooter.dc.html → Footer
   ProductCard.dc.html → components/product/ProductCard.tsx
   store.js → lib/catalogue.ts + lib/cart-store.ts (copy every product field and every string VERBATIM, same ids, same cart API and localStorage key)
   motion.js → components/motion/* (same maths: pinned progress = -rect.top/(height-innerHeight), parallax = (centre - viewportCentre) * -factor, reveal threshold .12 / rootMargin -8%, magnetic ±3px/±2px, cursor 84px)
   hero-scene.js → components/home/HeroScene.tsx in React Three Fiber, porting EVERY mesh dimension/position, material value, light (type, colour, intensity, position, shadow settings), procedural texture generator, fog, tone mapping, exposure curve, camera path, view-offset curve and damping exactly.
   image-slot.js / support.js are prototype runtime only — do NOT port; replace each <image-slot> with a next/image wrapper (same id as filename key, same aspect ratio, same backdrop colour, same caption shown as placeholder until an image exists).
2. Markup → JSX 1:1. Each .dc.html file has a template between <x-dc> and </x-dc> and a logic class in <script data-dc-script>. Keep the same element hierarchy and the same order of sections.
3. Styles: every inline style value is final. Convert to Tailwind using arbitrary values where needed (e.g. text-[clamp(52px,8.6vw,150px)], tracking-[-.03em], [font-stretch:82%]) — never round to the nearest Tailwind default. Keep every clamp(), calc(), aspect-ratio, transition duration and cubic-bezier exactly. Styles that read CSS variables (--hp, --sp, --in, --py, --h, --mx, --my, --r) must be reproduced with identical formulas (drive the variables from GSAP/Framer/useScroll, or set the same CSS vars).
4. "style-hover" attributes = hover state (Tailwind hover:). "data-reveal", "data-parallax", "data-pin", "data-cursor", "data-magnetic", "data-theme" = behaviours from motion.js — implement as components/hooks with the same semantics.
5. Logic: port each renderVals()/state/handler to hooks with identical behaviour, thresholds and breakpoints (900px mobile nav/filters/story layout, 700px height & 640px width for the scroll cue, 760px collection tile wrap).
6. Copy: use every string exactly as written in the reference files (headlines, eyebrows, buttons, captions, empty states, checkout notes, accordion text in Product.dc.html, collection copy in Collections.dc.html, principles in Home.dc.html). Do not add or remove copy, sections, badges or icons.
7. Verify: after each page, open the reference .dc.html in a browser next to your page at 1440px, 1024px and 390px wide and fix every visible difference before moving on. Scroll through pinned sections and compare at the same scroll positions.

=== SPECIFICATION ===
Build a complete premium ecommerce site for HALDEN — a fictional Zürich-based brand selling professional/home gym equipment, fitness accessories and home/lifestyle objects. It must feel custom art-directed (luxury fitness × modern architecture × editorial fashion ecommerce), never template-like.

STACK
Next.js (App Router) + TypeScript + Tailwind CSS + Framer Motion + GSAP ScrollTrigger + React Three Fiber/drei (hero only, loaded via next/dynamic ssr:false) + lucide-react + next/image + next/font/google. shadcn/ui only for Sheet, Select, Accordion, Checkbox. Zustand (persist) for cart. Create a clean folder/component structure first, then implement section by section.

STRUCTURE
app/(store)/page.tsx (Home) · app/(store)/shop/page.tsx (searchParams ?c=Strength|Cardio|Accessories|Home, ?line=gym|home) · app/(store)/products/[id]/page.tsx · app/(store)/collections/page.tsx · app/checkout/page.tsx (minimal layout)
